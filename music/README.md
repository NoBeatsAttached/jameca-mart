# Custom music

Drop audio files in this folder with these exact names. Each one replaces the built-in chiptune for that part of the game. Any file that's missing falls back to the chiptune.

| File | Plays during |
|---|---|
| `world.mp3` | Title screen, exploring, daytime |
| `blackout.mp3` | Wednesday blackout night |
| `battle.mp3` | Regular fights |
| `boss.mp3` | Boss fights |

Loops automatically. The in-game MUSIC VOL slider controls these too.
